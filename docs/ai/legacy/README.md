# Legacy notes (second-generation engine)

Research notes written for the removed "best effort" battle engine (`src/models/PvPTeam.ts` and friends, deleted
2026-10-24; see git history before branch `remove-gen2`). The game facts in them still hold unless `MECHANICS.md`
says otherwise; references to code files, functions and line numbers point at code that no longer exists.

- `PVE_PARAMS_3.19.md`, `PVE_ENEMY_AI_3.19.md`, `GAME_TABLES_3.19.md`: game research (enemy parameters, enemy AI,
  effect string -> class table).
- `MISSING_AND_UNCERTAIN.md`: the old engine's revision log (R4..R11) with derivations still cited from MECHANICS.md.
- `BATTLE_LOGIC_AUDIT.md`: an audit of the old engine against the decompile.
