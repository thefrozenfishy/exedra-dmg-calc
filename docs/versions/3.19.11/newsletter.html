3.19.11: one lottery field changed, the battle engine did not

The 5 October patch (Steam files dated 2026-10-05 18:26 UTC) is the first client since 3.19.0 with a real code change. It touches only the lottery event's number limit. Every battle function is byte-identical, so the simulator needed no changes this time.

Compared: unpackedExedra 3.19.0 → 3.19.11 (the 3.19.1 unpack is no longer on disk) · global-metadata v31 · base_data 4ea7254^ → HEAD

CODE CHANGED

1,577 bytes of code changed, all in the lottery. The diff touches 3 functions: LotteryMstRecordUnpacker.TryReadByIndex, LotteryMstModel.get_DisplayableLotteryNumberDigit and get_IsSetLotteryNumberUpperLimit. lotteryNumberUpperLimit (record offset 0x20) went from a 32-bit to a 64-bit integer: mov ecx,[rax+20h] became mov rcx,[rax+20h]. The il2cpp section is the same size and nothing after those functions moved.

BATTLE CODE IDENTICAL

Every ReDriveBattleCore function is unchanged and at the same address. All RVAs in the knowledge base and the 3.19.0 decompile stay valid. Il2CppDumper and Ghidra are only needed to get the new names on record, not for the simulator.

Aqua Tempest

5★ Aqua BufferSorana Nagiboshireleased 4 Oct 22:00 JST

She brings the new unique state Orchestration (pattern 32). Her ability cuts DMG taken from all-target attacks, which uses the new condition "attacker's skill range" (content 403). Her EX crys, What Does the Future Have in Store for Me Now?!, advances action order by 10% and grants 5 MP on basic attacks. Her portraits include Orbit of SORA (+20% SPD) and Noontide in a Sunken City (+20% aqua DMG).

A BP-based ultimate, a flame field (Flame Field, 10004) and Ember Feather (30). The 3.19.1 dispatch has her full kit.
