Madoka Exedra · version dispatch · 15 Oct 2026

3.21.0: step-up skills and HP-cost skills arrive in the code, not yet in the data

The 15 October patch (Steam files dated 2026-10-15 16:12 UTC, build of 8 Oct) is a real rebuild of the game code. The metadata names two new battle mechanics, Step-Up skills and a self-HP-cost effect, plus an EX character bonus for Link Raid. No master data uses any of them yet, and the battle code can't be read until a new Il2CppDumper dump exists.

Compared: unpackedExedra 3.19.11 → 3.21.0 · global-metadata v31 · base_data 932c14c → HEAD (e24b0a1) · ma-ex-data download of 15 Oct 16:38

CODE CHANGED

GameAssembly grew by 446,464 bytes and the layout moved. 1,838 pages of .text and 21,805 pages of il2cpp differ, so every RVA from 3.19 may have shifted. The 3.19.0 decompile no longer describes this client.

BLOCKED

The engine port waits for Il2CppDumper and Ghidra on Windows. The simulator still matches 3.19 behaviour. All the new mechanics are unused by current data, so today's battles are unaffected. The commands are at the bottom of this page.

What's new in the game

New mechanics, read from the metadata

Il2CppDumper hasn't run yet, so these come from the identifier and literal strings in global-metadata.dat (1,938 new identifiers, 1,026 gone, 104 new literals). The names are exact; what the code does with them isn't known yet.

Step-Up skills

STEP_UP_SKILLbattle core

A skill that can be enhanced level by level by paying extra SP before using it. New names include StepUpSkillUnitState, CommandStepUpSkill, CanStepUpSkill, CanStepUpFurther, CalcStepUpTotalConsumeSp, StepUpConsumeSp, SetOverrideConsumeSp, GetActiveStepUpLevel, nextSkillMstId / nextStepLevel, and GetStepUpSkillByPassiveSkill, so the step-up comes from a passive. Auto battle has its own rule, ShouldUseStepUpSkillByRole and TrySelectStepUpActiveSkills. Sound cues se_battle_skill_stepup_enhance and …_reset_01 suggest the level resets after use.

Self HP cost

CONSUME_SELF_HPability effect

A new ability effect class ConsumeSelfHpAbilityEffect with fields consumeHpRatio and consumeHpFixed (percent of HP and a flat amount), a CreateByConsumeHp damage-result path and a fly-text BattleFlyTextConsumeHpIn. Neither new type is in AbilityEffectTypeMst yet.

Link Raid EX character bonus

MultiRaid

MultiRaidMst gained exCharacterBonusGroupId and exCharacterBonusPassiveSkillMstId, with a new table MultiRaidExCharacterBonusMst (the UI calls it "EXボーナス"). All 30 seasons have 0 in both fields and the new table is empty. It will give a passive to listed characters once a season sets it.

Outside battle

  • Shop: bulk exchange (/api/shop/bulk_buy), recommended exchanges and settings, payment notices for unclaimed Web Shop items.
  • Profile shows the highest Mirror Tower floor cleared (towerHighestFloor).
  • A special enemy death direction (EnemySpecialDeathDirection, Anomaria Sayaka sequences) and style voice overrides (StyleOverrideVoiceMst, empty).
  • Removed: user comment / title / favourite APIs, Firebase Dynamic Links and Invites.

Master data

  • No new kiokus, stages, effect types or conditions, and no balance changes, either in base_data since 3.19.11 or in today's download.
  • base_data e24b0a1 (8 Oct): one school name, 30 missions removed. Today's download: one home banner, 55 missions removed, 189 shop series get isRecommendExcluded, Live2D params.

Needs you

Dump and decompile 3.21.0

1. Il2CppDumper (PowerShell, in E:\Il2CppDumper; press a key at the end):

.\Il2CppDumper.exe "E:\unpackedExedra\3.21.0\GameAssembly.unpack.dll" "E:\SteamLibrary\steamapps\common\MadokaExedra\MadokaExedra_Data\il2cpp_data\Metadata\global-metadata.dat" "E:\unpackedExedra\3.21.0\dump"

2. Ghidra headless, per E:\unpackedExedra\Ghidra\README_headless.md: make_name_lists.py on the 3.21.0 dump, import, DecompileList into E:\unpackedExedra\3.21.0\decompiled (needs ~6 GB heap).

3. Then the next run does verdiff.py funcs, ledger.py --check, re-ports the moved and changed battle methods, and ports Step-Up and CONSUME_SELF_HP.

  • Optional: sync base_data from today's download (only mission, shop and banner rows change).
  • Merge claude/version-3.21.0 when you're happy with it. The full machine report is in docs/versions/3.21.0/report.md.
